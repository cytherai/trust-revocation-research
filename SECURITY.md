# Security

To report an error in our findings, a problem with the evidence, or a
vulnerability in the scripts, use **Report a vulnerability** on this
repository's Security tab. The report reaches the maintainers privately.
Please don't open a public issue for anything that could put users at risk.

When our research finds a vulnerability in someone else's software, we report
it privately to the maintainers first. We publish after a fix, or after a
disclosure window agreed with them. Our disclosure records are in
`disclosures/`.
